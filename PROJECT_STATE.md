# Taiwan Family Trip Pages Project State

This is the public GitHub Pages frontend for the Taiwan Family Trip project.

## Related Project
- Data/crawler repo: `/config/TW-FamilyTrip-Data`
- Public pages repo: `/config/TW-FamilyTrip-Pages`

## Purpose
Display curated Taiwan family outing recommendations. `data.json` is generated by `TW-FamilyTrip-Data`.

## Important Files
- `index.html`: single-file Tailwind CDN frontend
- `data.json`: generated recommendation data

## Notes
- Prefer changing crawler/data generation in `/config/TW-FamilyTrip-Data` unless the task is specifically frontend UI.
- Enable GitHub Pages from `main` / root in repository settings.
