# TW-FamilyTrip-Pages

Public GitHub Pages frontend for Taiwan family outing recommendations.

- `index.html`: single-file Tailwind CDN frontend.
- `data.json`: generated by `TW-FamilyTrip-Data` and pushed here by GitHub Actions.

Enable GitHub Pages from `main` / root in repository settings.

## Manual frontend updates

`data.json` is updated automatically by the private `TW-FamilyTrip-Data` workflow, so this repo may advance even when only data changed. Before pushing manual frontend edits, sync first:

```bash
git pull --ff-only origin main
```

Then commit and push the frontend files, such as `index.html`.
